# Slide Patterns Reference

Common slide layouts and when to use them. Load this when planning specific slides.

## Layout Patterns

### Title Slides

**Standard title**
- Large title centered
- Subtitle or tagline below
- Presenter name / date at bottom
- Use: Opening slide, first impression

**Bold statement title**
- Single provocative statement
- No subtitle
- Use: When the title IS the message

**Image title**
- Full-bleed background image
- Title with contrast overlay
- Use: Visual impact, setting tone

---

### Section Dividers

**Text divider**
- Section name large and centered
- Minimal other elements
- Use: Separating major parts, giving audience a mental break

**Numbered divider**
- Large number + section name
- Use: When sequence matters (e.g., "Step 2 of 4")

**Icon divider**
- Simple icon + section name
- Use: Visual variety, thematic sections

---

### Content Slides

**Single message**
- One bold statement, large text
- Nothing else
- Use: Key takeaways, memorable moments

**Bullet points**
- Headline + 3-5 bullets max
- Use: Lists, steps, features (sparingly)

**Two column**
- Left: Text or context
- Right: Supporting content
- Use: Compare/contrast, image+text, data+interpretation

**Three column**
- Three equal sections
- Use: Three options, three pillars, three features (never more)

---

### Data Slides

**Big number**
- Oversized statistic (100pt+)
- Context label below
- Use: Impact metrics, headline findings

**Single chart**
- One chart, full focus
- Headline states the takeaway (not "Q3 Sales" but "Q3 Sales Up 20%")
- Use: Data that speaks for itself

**Chart + interpretation**
- Chart on one side (60%)
- 2-3 bullet points on other side (40%)
- Use: Complex data needing explanation

**Comparison table**
- 2-4 columns, 3-5 rows max
- Highlight key differences
- Use: Feature comparisons, competitive analysis

---

### Visual Slides

**Full-bleed image**
- Image covers entire slide
- Text overlay with contrast
- Use: Emotional impact, context setting

**Image + caption**
- Image takes 70% of slide
- Caption or explanation below
- Use: Case study photos, product shots

**Image grid**
- 2-4 images in grid
- Brief labels if needed
- Use: Multiple examples, portfolio, team

---

### Quote Slides

**Centered quote**
- Quote in large text, centered
- Attribution below, smaller
- Use: Customer testimonials, expert opinions

**Quote + context**
- Quote on one side
- Photo or context on other
- Use: When the source matters visually

---

### Process Slides

**Timeline**
- Horizontal flow with milestones
- Dates or phases labeled
- Use: Roadmaps, history, project plans

**Steps**
- Numbered steps, left to right or top to bottom
- Use: How-to, process explanation

**Cycle**
- Circular arrangement
- Arrows showing flow
- Use: Recurring processes, feedback loops

---

### Closing Slides

**Summary**
- 3-5 key takeaways
- Use: Reinforcing main points

**Call to action**
- One clear next step
- Contact info if relevant
- Use: Final slide, what to do now

**Q&A**
- "Questions?" or similar
- Contact info optional
- Use: Inviting discussion

---

## Layout Selection Guide

| Content type | Recommended layout |
|--------------|-------------------|
| Key insight | Single message |
| Feature list | Bullet points (max 5) |
| Data finding | Big number or single chart |
| Comparison | Two column or table |
| Testimonial | Centered quote |
| Process | Timeline or steps |
| Visual example | Full-bleed or image+caption |

## Common Mistakes

**Avoid:**
- More than 5 bullets on one slide
- Charts + bullets + images on same slide
- Walls of text
- Title that describes topic instead of takeaway
- Inconsistent layouts throughout deck

**Instead:**
- Split dense slides into multiple slides
- One idea per slide
- Headlines that state the point
- Consistent visual rhythm
